Trois façons de ranger les réglages d'un script — 1 ligne par option

Même contenu réel (le script « Désactiver la veille » de ton test), trois mises en page. Redimensionne la fenêtre ou compare simplement les trois colonnes.

A — Contrôle aligné à droite

Le plus dense. Le regard descend une colonne de libellés à gauche, une colonne de contrôles à droite — lecture en deux passes verticales. Fonctionne bien tant que les contrôles restent courts (interrupteur, petit nombre).

C — Table alignée avec clé technique

Trois colonnes strictement alignées : la clé technique (utile en mode Expert pour retrouver l'option dans le script), le libellé + description sur une seule ligne, le contrôle à droite. Le plus compact des trois, mais la clé technique occupe une place que le grand public n'a pas besoin de voir.

Ma préférence irait à A pour le mode Simple (dense, scannable) et C pour le mode Expert (la clé technique y a sa place). B reste utile pour un texte libre avec une description longue. Dis-moi laquelle retenir — ou un mélange (ex. A partout, description en tooltip plutôt qu'affichée).
