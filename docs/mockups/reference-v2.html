Risque déclaré par l'auteur : faible 2 points d'attention détectés

Le niveau de risque ci-dessus est écrit par l'auteur du script — il n'a aucune valeur si le script est malveillant. Ce qui suit est détecté automatiquement par WinTool.

Ligne 14 — Invoke-Expression
Exécute du texte comme s'il s'agissait de code PowerShell — souvent utilisé pour cacher ce qu'un script fait réellement.
Ligne 22 — DownloadString
Télécharge du contenu depuis Internet pendant l'exécution.

Détection indicative, non exhaustive — un script malveillant peut la contourner. En cas de doute, lisez le script ou demandez à quelqu'un de confiance de le faire.
